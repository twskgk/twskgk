# Примеры диаграмм и блок-схем в Mermaid

В этом файле собраны основные типы диаграмм, которые можно строить с помощью синтаксиса Mermaid в Markdown.

## 1. Блок-схема (Flowchart)
Отображает алгоритмы, логику процессов и разветвления условий.

```mermaid
graph TD
    Start([Начало процесса]) --> Input[/Ввод данных/]
    Input --> Condition{Данные верны?}

    Condition -->|Да| Process[Обработка данных]
    Condition -->|Нет| Error[/Ошибка/] --> Input

    Process --> End([Конец])
```


## 2. Диаграмма Ганта (Gantt Chart)
Используется для планирования задач, управления проектами и отображения временных шкал.

```mermaid
gantt
    title План разработки проекта
    dateFormat  YYYY-MM-DD
    section Подготовка
    Анализ требований           :a1, 2026-10-01, 5d
    Проектирование базы данных  :after a1, 7d
    section Разработка
    Создание API                :2026-10-10, 10d
    Фронтенд интерфейс          :2026-10-15, 12d
```

## 3. Круговая диаграмма (Pie Chart)
Отлично подходит для наглядного отображения долей, процентов или статистики.

```mermaid
pie title Используемые языки в проекте
    "TypeScript" : 45
    "Python" : 30
    "HTML/CSS" : 15
    "Go" : 10
```

## 4. Блок-схема слева направо с подграфиками (Subgraphs)
Позволяет группировать элементы логически в отдельные визуальные блоки (кластеры).

```mermaid
graph LR
    subgraph Frontend [Клиентская часть]
        A[Интерфейс] --> B(Валидация формы)
    end
    
    subgraph Backend [Серверная часть]
        C[Контроллер API] --> D[Бизнес-логика]
    end
    
    B -->|HTTP POST| C
```

## 5. Стилизованная блок-схема (Кастомные цвета)
Пример изменения цвета блоков, обводки, текста и стрелок с помощью операторов `style` и классов.

```mermaid
graph TD
    Node1[Стандартный блок] --> Node2[Важный шаг]
    Node2 --> Node3[Успех]
    
    style Node2 fill:#ffcccc,stroke:#ff0000,stroke-width:2px,color:#000
    style Node3 fill:#ccffcc,stroke:#00aa00,stroke-width:2px,stroke-dasharray: 5 5
```

## 6. Диаграмма «Сущность-Связь» (ER-Diagram)
Используется в проектировании баз данных для описания таблиц, их полей (ключей) и связей между ними.

```mermaid
erDiagram
    CUSTOMER ||--o{ ORDER : places
    ORDER ||--|{ LINE-ITEM : contains
    
    CUSTOMER {
        string id PK
        string name
        string email
    }
    ORDER {
        int id PK
        string customer_id FK
        date order_date
    }
```

## 7. Ментальная карта (Mindmap)
Удобный инструмент для брейншторма, фиксации идей, создания структуры контента или планов.

```mermaid
mindmap
  root((План обучения))
    Frontend
      HTML / CSS
      JavaScript
      Frameworks
        React
        Vue
    Backend
      Node.js
      Python
      Databases
```

## 8. Диаграмма состояний (State Diagram)
Показывает жизненный цикл объекта или системы и условия перехода из одного состояния в другое.

```mermaid
stateDiagram-v2
    [*] --> Черновик
    Черновик --> На_проверке : Отправить статью
    На_проверке --> Черновик : Отклонить с правками
    На_проверке --> Опубликовано : Утвердить
    Опубликовано --> [*]
```

## 9. Диаграмма классов (Class Diagram)
Применяется в ООП (объектно-ориентированном программировании) для визуализации структуры кода, классов и методов.

```mermaid
classDiagram
    Animal <|-- Duck
    Animal <|-- Fish
    Animal : +int age
    Animal : +string gender
    Animal: +isMammal()
    Animal: +mate()
    
    class Duck{
        +string beakColor
        +swim()
        +quack()
    }
```


## 10. Карта пользовательского пути (User Journey)
Используется UX/UI-дизайнерами и маркетологами, чтобы разложить по шагам действия пользователя и его эмоции.

```mermaid
journey
    title Покупка кофе в приложении
    section Поиск кофе
      Открыть приложение: 5: Пользователь
      Выбрать капучино: 4: Пользователь
    section Оплата
      Ввести данные карты: 2: Пользователь, Сложно
      Успешная оплата: 5: Система
```

## 11. Квадрант-диаграмма (Quadrant Chart)
Помогает распределять задачи, продукты или риски по матрице 2х2 (например, Важно/Срочно).

```mermaid
quadrantChart
    title Анализ задач по матрице Эйзенхауэра
    x-axis Низкая срочность --> Высокая срочность
    y-axis Низкая важность --> Высокая важность
    quadrant-1 Сделать немедленно
    quadrant-2 Запланировать время
    quadrant-3 Делегировать
    quadrant-4 Удалить / Не делать
    Задача А: [0.7, 0.8]
    Задача Б: [0.2, 0.6]
```

## 12. Хронология (Timeline)
Наглядная шкала для отображения исторических событий, дорожных карт (Roadmaps) или релизов по годам.

```mermaid
timeline
    title Эволюция веб-технологий
    1991 : Появление WWW : HTML 1.0
    1995 : Рождение JavaScript : CSS
    2015 : Релиз ES6 : Настоящий бум фреймворков
```
